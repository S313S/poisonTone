## 手工步骤

1. 打开 HTTPS 测试地址，确认 360—430px 宽无横向滚动。
2. 拍照、取消拍照、选相册、重复选同一张、选 HEIC 与超大图；记录预览方向和错误文案。
3. 分别允许、拒绝与超时定位；允许时记录返回的**粗粒度**地点是否合理。测试记录不要写精确坐标。
4. 相册旧照不确认时间和地点后生成，检查文案没有当成拍摄事实。
5. 用真模型分别测试照片和纯文字；复制后粘贴到备忘录核对“（AI生成）”；断开剪贴板权限后检查长按方案。
6. 生成途中换图，确认旧结果不覆盖新画面；换一批不再请求定位。

浏览器模拟位置或局域网 HTTP 测试不算中国大陆真机自动定位验收。`tests/roast-cases.json` 当前是描述型夹具，`visualCovered: false` 表示尚未覆盖真实视觉输入。
