# 现场毒舌 MVP 实施计划

**目标：**按用户提供的 v0.1 规格完成手机优先的真实模型 H5 工程。

**架构：**Next.js App Router 单仓；客户端负责拍照、图片重编码、单次定位、同意说明和结果状态；Route Handlers 负责限额、图片验证、地图逆地理编码、模型调用和白名单事件。

**技术：**Next.js、TypeScript、Sharp、原生浏览器 API、Node 测试运行器。

1. 建工程和独立 Prompt 模块；安装锁文件依赖。
2. 测试优先实现输入、输出、图片与事件校验，再实现三个 API。
3. 接入高德 GPS 坐标转换及逆地理编码；接入兼容模式多模态接口。
4. 完成手机输入与结果页面、权限分支、请求取消和复制降级。
5. 建 20 个场景夹具、README、真机清单和部署说明；运行测试、类型检查、lint、构建和浏览器验收。
