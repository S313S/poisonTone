# 现场毒舌 MVP v0.1

手机 H5：拍照／相册或一句话，经过确认后将现场素材发给配置的视觉模型，生成三条中文吐槽。照片和结果只在当前页面及请求内存中处理，本应用不建立历史库。

## 本地运行

需要 Node 20.9+。执行：

```bash
npm ci
cp .env.example .env.local
npm run dev
```

打开 `http://localhost:3000`。默认是真实模式；未填模型配置时会明确报错，不会生成假结果。本地只体验界面时，手动将 `.env.local` 中 `DEMO_MODE=true`，重启服务，页面会持续显示“演示数据，非实时 AI 生成”。演示文案是占位数据，不能用于评估真实模型质量。

## 真实服务配置

在 `.env.local` 或部署平台的服务端环境变量中填写 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`、`AMAP_WEB_SERVICE_KEY`、`APP_ORIGIN`。`LLM_BASE_URL` 是兼容接口的 **v1 根地址**，不包含 `/chat/completions`；地域、业务空间和具备视觉及 JSON 输出能力的模型以供应商账号实际权限为准，不在工程里猜测模型名。模型和地图 Key 均不可使用 `NEXT_PUBLIC_` 前缀。

当前本地真实模式已试用阿里云百炼的 `deepseek-v4.1-flash`，模型名填入 `LLM_MODEL`；原有百炼 API Key 和业务空间的兼容接口根地址沿用。首次生成和“快速换一批”关闭深度思考；结果页可按“深度开喷”重新生成三条，并开启深度思考。一次虚构文字输入的快速与深度请求分别约需 6.4 秒和 18.0 秒；耗时随输入和服务状态变化，另一次浏览器深度请求超过了原来的 35 秒限制。现在快速请求最多等待 35 秒，深度请求最多等待 60 秒。等待区显示实际已等待秒数和不表示完成比例的动画；深度等待时可玩“真心话 / 嘴上大冒险”，快速等待超过 8 秒也可主动打开。修改 `.env.local` 后请重启本地开发服务；线上需在部署平台单独修改环境变量并重新部署。

纯文字路径不需要照片；自动地点需要地图 Key。地图配置缺失时可以手动填写地点或跳过。首次模型请求前页面会展示单独的云端发送说明。
